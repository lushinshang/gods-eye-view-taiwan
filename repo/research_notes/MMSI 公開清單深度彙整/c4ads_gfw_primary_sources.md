## C4ADS reports — do they publish MMSI tables for China Coast Guard, maritime militia, or research vessels?

### Takeaway
C4ADS's November 2021 report *Pulling Back the Curtain on China's Maritime Militia* (co-published with CSIS/AMTI) does contain real vessel-name-to-MMSI tables in Appendix A and Appendix B, but these cover identified/likely **maritime militia fishing vessels**, not China Coast Guard or dedicated research vessels. I downloaded and text-extracted the PDF directly rather than relying on summaries. I could not locate a C4ADS report titled "Harbored Ambitions" or "Shining a Light" (searches for these exact titles returned no matching document); it's possible these titles are misremembered or belong to a different publisher.

### Inferences
- C4ADS's methodology for its maritime militia report clearly supports building vessel-name-to-MMSI tables when the underlying AIS/registry data is available — the Appendix A/B format (vessel name, city of registration, MMSI, direct owner, ultimate beneficial owner) is a reusable template for a "known vessel" cross-reference list, but C4ADS's own published work in this vein targets **militia fishing vessels**, not CCG cutters or research ships.
- Given that C4ADS/JAC's squid-fleet MMSI work (JAC-010) explicitly treats "412-series" MMSIs as assigned to Chinese-flagged vessels generally (not militia- or CCG-specific), any China Coast Guard MMSI (which commercial AIS aggregators place in the same 412/413 MID block, e.g. 413875xxx range per search snippets) would be structurally indistinguishable from an ordinary Chinese-flagged vessel MMSI without an external name/owner cross-reference — which is exactly the gap C4ADS's militia report fills only for fishing vessels, not CCG hulls.

## Does Global Fishing Watch's vessel registry/API allow lookup of Chinese government/research/CCG vessels by MMSI?

### Takeaway
Global Fishing Watch's vessel identity system is built around MMSI (which GFW internally calls "ssvid") plus IMO, callsign, name, and flag, matched against vessel registries — but GFW's registry and matching logic is scoped to **fishing, carrier, and fishing-support vessels**; no source confirms it includes China Coast Guard or research vessels as a category, and GFW's own public vessel map/API is explicitly fisheries-focused, making it an unlikely source for CCG/research-vessel identity data. This is an inference from documentation on scope, not a confirmed exclusion statement — see Gaps.

### Cited Findings
- GFW's vessel info tables use "ssvid" (source-specific vessel identity) as their internal name for the AIS MMSI field: "MMSI is referred to as ssvid in our tables." [Source](https://globalfishingwatch.github.io/GFW_technical_documentation/Vessel-info-tables)
- The registry_info section of GFW's vessel info tables holds "identity information tied to each MMSI from vessel registries," with fields including MMSI number, shipname, callsign, IMO number, and flag. [Source](https://globalfishingwatch.github.io/GFW_technical_documentation/files/vessel-info-tables.html)
- A vessel record is flagged "matched" when AIS and registry data "sufficiently close in multiple fields among name, callsign, IMO, MMSI number, and flag." [Source](https://globalfishingwatch.github.io/GFW_technical_documentation/files/vessel-info-tables.html)
- IMO numbers are "required for only a subset of industrial fishing vessels" and are frequently missing from AIS messages even when assigned. [Source](https://globalfishingwatch.github.io/GFW_technical_documentation/files/vessel-identity.html) (via search snippet; direct fetch of this exact page returned HTTP 404 in this session, so this is cited from the search-result snippet, not a verified direct read — treat as lower-confidence)
- As of a stated "June 2026" change, GFW's API reference data notes manually ingested IMO records for fishing and fishing-support vessels are being retired/superseded by S&P Global (SNP) data, "a limited set of static IMO records is retained for selected non-fishing vessels" — implying GFW's registry does carry at least some non-fishing-vessel records, but doesn't specify whether these include government/CCG vessels. [Source](https://globalfishingwatch.org/our-apis/documentation/docs/v3/general-api-doc/reference-data) (via search snippet, not directly fetched)

### Inferences
- GFW's core identity-matching pipeline (AIS ↔ registry matching on name/callsign/IMO/MMSI/flag) is a general-purpose vessel identity system, but its registries and primary use case are built around commercial fishing vessel oversight (combating IUU fishing), not military/law-enforcement vessel tracking. The "limited set of static IMO records... retained for selected non-fishing vessels" suggests GFW's registry is not purely fishing-only, but there's no evidence it specifically targets or curates CCG/research vessel identities.

### Gaps
- Could not directly confirm whether China Coast Guard or Chinese research vessels appear at all in GFW's public vessel search/API (direct fetch of https://globalfishingwatch.github.io/GFW_technical_documentation/Vessel-database and the vessel-identity.html page both returned HTTP 404 in this session — possibly due to a redirect/URL structure change on GFW's docs site). A follow-up should try GFW's API vessel search endpoint directly (https://globalfishingwatch.org/our-apis/documentation/docs/v3/vessels/search) with a China Coast Guard vessel name as a live test query, which this task did not attempt.
- No definitive statement found (primary or secondary) that GFW's registry explicitly excludes or includes government/law-enforcement vessels as a policy matter — this remains unresolved.

## Do Taiwanese government sources (CGA/OAC/Legislative Yuan) publish MMSI numbers alongside Chinese vessel names?

### Takeaway
No Taiwanese government press release, Legislative Yuan record, or Control Yuan (監察院) report found in this search names specific MMSI numbers for Chinese Coast Guard vessels; Taiwanese sources consistently describe the problem in terms of vessels going "dark" (turning off AIS) or using hull/pennant numbers (舷號) for identification, treating MMSI/AIS spoofing as an enforcement problem rather than publishing a reference list.

### Cited Findings
- CNA (中央社) reported the Dongsha Command Headquarters detected "China Coast Guard 3102" (中國海警3102) navigating without AIS turned on ("暗船" / "dark ship" tactic) near Dongsha Atoll; the report states Taiwan's Coast Guard Administration has driven off Chinese coast guard vessels from Dongsha restricted waters 13 times (16 vessel-instances) so far this year. No MMSI given — vessel identified only by name/pennant. [Source](https://cna.com.tw/news/asoc/202610310133.aspx)
- A Legislative Yuan interpellation (KMT legislator 陳永康) cited in news coverage noted that on a specific day, 15 Chinese commercial vessels were in restricted waters and 30 vessels could not be identified because they had turned off AIS. [Source](https://udn.com/news/story/124909/9556448) (via search snippet, not directly fetched)
- A Control Yuan (監察院) document (direct fetch returned HTTP 404 in this session, title unconfirmed) is referenced in search results as stating that gray-zone maritime activity "often uses turning off AIS or misusing another vessel's MMSI (水上行動業務識別碼) to conceal its movements," and recommends the Executive Yuan coordinate relevant agencies on countermeasures. [Source](https://cybsbox.cy.gov.tw/CYBSBoxSSL/edoc/download/71555) — **could not independently verify this content via direct fetch (404); this finding is sourced only from the search-engine-generated summary snippet, not a verified read of the document itself. Treat as unconfirmed/lower-confidence.**
- A separate AIS-related incident report describes a Taiwanese-flagged fishing boat's AIS briefly displaying a Chinese-flag-pattern MMSI, attributed by Taiwan's Coast Guard Administration (Southern Branch, vessel PP-3559) to onboard Chinese-made fishing-gear transponders rather than an actual change of vessel identity — illustrating that Taiwanese CGA statements address MMSI anomalies case-by-case rather than via a published cross-reference list. [Source](https://udn.com/news/story/7320/9416266) (via search snippet, not directly fetched)

### Inferences
- Taiwanese government discourse on Chinese vessel identification centers on pennant/hull numbers (舷號, e.g., "中國海警3102," "秀山艦" with 舷號二三○五) and AIS presence/absence as a binary enforcement signal, not on maintaining or publishing a name-to-MMSI reference table. This suggests that if a MMSI cross-reference for CCG vessels is needed, it will have to come from commercial AIS aggregators (MarineTraffic, VesselFinder, MagicPort) or foreign/NGO analytical work, not from Taiwanese government publications.

### Gaps
- Could not directly access or verify the Control Yuan document at cybsbox.cy.gov.tw/CYBSBoxSSL/edoc/download/71555 (404 on direct fetch) — its exact title, date, and full text are unconfirmed; only a search-snippet summary was obtained.
- Did not check Taiwan's Ocean Affairs Council (oac.gov.tw) or Coast Guard Administration (cga.gov.tw) official press-release archives directly (e.g., via their own site search) — only general web search was used, which may have missed official press releases not well-indexed by the search engine. This is a reasonable next step if more research time is available.
- Did not find any Legislative Yuan committee report or budget-review document that lists MMSI numbers; only interpellation summaries from news coverage were found.

MUTABILITY & LIFECYCLE HIERARCHY

數據時效三大層級：不可變動、不用變動、動態頻率

在指揮戰情系統中，混淆數據的時效特質會導致不必要的伺服器負載與架構混亂。我們嚴格劃分三大層級：

IMMUTABLE
不可變動層
代表客觀發生的歷史事實與實體時空記錄。一旦寫入即具有法律與事後追溯效益，嚴禁任何回溯覆寫或人為竄改。
  • 臺灣海域 7 天歷史航跡庫 Append-only NDJSON
  • USGS 已定案歷史地震紀錄 Seismic Event ID
  • 警廣已結案道路重大事故日誌 Archived Incident
STATIC / QUASI-STATIC
不用變動層
物理硬體基礎設施、地表幾何拓撲與本機推論權重。日常系統運作期間常態唯讀，數月至數年無須頻繁更新。
  • 海底光纖通訊電纜海床路由 3~5 年重大工程更新
  • 基礎衛星底圖與 3D 建築網格 Esri / Google 3D
  • 國道攝影機實體樁號門架坐標 1,800 支坐標固定
  • 本機 Ollama AI 模型靜態權重 Gemma / Llama 離線
DYNAMIC REFRESH
動態遙測層
隨時間即時流轉的海陸空即時狀態。依物理移動速度與 API 承載力，設定從毫秒串流到小時級數值模擬之刷新週期。
  • 全球民航與軍機航跡 (OpenSky) 5 ~ 10 秒
  • 國道攝影機即時路況快照 (CCTV) 5 ~ 15 秒
  • 臺灣商漁船 AIS 動態 (航港局) 40 秒快取合併
  • 全球數值風場預報 (NOAA GFS) 每 6 小時計算
